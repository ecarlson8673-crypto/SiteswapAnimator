Siteswap Notation Explained

What Is Siteswap Notation

Siteswap notation is a way of representing juggling patterns using numbers and symbols.

How Siteswap Notation Works

Every single siteswap can be imagined as an infinite repeating string of numbers. But, because the string of numbers repeats, it can be compressed to a way shorter string of number. For example 531 is actually 531531531 ect. But because it repeats we just say 531. When this program animates a pattern it runs through the pattern like this, pretending it is an infinite string of numbers.

The numbers in a siteswap represent different throws. Odd throws cross to the other side while even throws stay in the same hand. The numbers also represent how many beats that throw is in the air for, each beat one ball is thrown. For example, in the siteswap 5 each ball is thrown so that it stays in the air for 5 beats. Because each ball is staying in the air for 5 beats and one ball is thrown each beat this is a 5 ball pattern. You can always calculate this by adding all the numbers in the siteswap together and dividing by the total number of numbers in the siteswap. For example, in the siteswap 531, 5 + 3 + 1 = 9 / 3 = 3 so this is a 3 ball pattern, in the siteswap 71, 7 + 1 = 8 / 2 = 4 so this is a 4 ball pattern. This only works for regulare patterns, not synchronous, muliplex, or synchronous multiplex patterns.
