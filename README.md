# Siteswap Animator
This program animates siteswaps. Siteswap notation is a way of representing juggling patterns with numbers and symbols.
Some patterns to try: 97531, 441, 71, 9, 8, 774, 645

Run this program here https://ecarlson8673-crypto.github.io/SiteswapAnimator/

### How It Works
Each number represents the number of beats a ball is in the air for. The higher the number the higher the ball will go. Odd numbers will cross to the other hand while even numbers stay in the same hand. Each beat one ball is thrown and one is caught. The hand throwing and catching alternates between each beat.
The first ball thrown uses the first number then the next ball thrown uses the next number and so on. Once all the numbers have been used the program goes back to the first number.
The number of balls in that pattern is the average of all the numbers in the pattern. For example 531 is a three ball pattern because 5 + 3 + 1 = 9 / 3 = 3 or 71, 7 + 1 = 8 / 2 = 4.

### Example
For the siteswap 5 the first ball thrown is thrown at a height of 5 beats so that 5 beats later it comes down. Then the next ball is also thrown at the same height because there is only one number in the pattern. For the siteswap 71 the first ball is thrown at a height of 7 beats then the next ball is thrown at a height of 1 beat. Then the next ball is thrown at a height of 7 beats and so on. To see a visual representation use the program.
